Finální balíček po závěrečné kontrole, 4. 11. 2026.

NAHRÁNÍ
Na hosting nahrajte obsah složky web tak, aby index.html a assets byly vedle sebe. Zachovejte všechny relativní cesty. Pro publikování z větve GitHub Pages použijte její kořenovou složku / nebo složku docs podle nastavení repozitáře. Samotná složka web v tomto ZIPu není automaticky publikační složkou GitHub Pages. Doména, HTTPS ani publikování se tímto ZIPem nenastavují.

STRÁNKY
index.html – hlavní stránka, služby a kontakty.
certifikace.html – certifikát z obrázku JPG bez doplňujících vět nad obrázkem.
obchodni-podminky.html – podmínky pro individuálně domlouvané zakázky.
ochrana-osobnich-udaju.html – informace o ochraně osobních údajů.
assets/header.css a assets/header.js – společné záhlaví, menu a tisková podpora všech čtyř stránek.

CERTIFIKÁT
Web používá pouze assets/certifikat-metrolog-page.jpg. PDF certifikátu bylo z výsledného balíčku odstraněno. Původní PDF si uchovejte samostatně. Obrázek JPG zůstal nezměněn; jeho alternativní text pro čtečky obrazovky byl zachován.

HOSTING
Po upřesnění účelu počítáme s GitHub Pages pro prezentační web: informace o poskytovateli, služby, certifikace a kontakty. Web nemá objednávky, platby ani uzavírání smluv na stránce. Posouzení vychází z pravidel a skutečné funkce webu, nejde o individuální souhlas GitHubu. GDPR stránka popisuje GitHub Pages jako skutečný hosting; při jeho změně ji upravte.

FUNKCE
Menu na všech stránkách používá stejnou obsluhu. Na mobilu se skryje až po její inicializaci. Přepínač světla a tlačítka kopírování se zobrazí až po inicializaci jejich obsluhy. Odkazy mailto/tel jsou použitelné i bez JavaScriptu. Obrázky a písma jsou místní; vlastní kód neukládá cookies ani web storage a neobsahuje analytiku.

KONTROLY
Aktuální podrobnosti jsou v KONTROLA-WEBU.md vedle složky web. Ověřeny zdroje, vazby mezi soubory a izolovaně logika skriptů. Vizuální kontrola aktuální verze v prohlížeči neproběhla: služba náhledu je nedostupná. Údaje o starších prohlížečových testech z původního balíčku nejsou ověřením této verze a nejsou zde přebírány jako aktuální výsledek.

PROVOZNÍ DOKUMENTY
KONTROLA-WEBU.md, GDPR-POKYNY.txt a EMAIL-GDPR.txt jsou určeny pro vás, ne k publikování. Před použitím potvrďte skutečný rozsah zpracování údajů a lhůty uchování; do e-mailového podpisu doplňte veřejný odkaz na GDPR stránku. Obchodní podmínky předávejte při sjednání zakázky v uchovatelné podobě.

LICENCE
Zdroje fotografií jsou v LICENCE-FOTOGRAFII.md a assets/photo-sources.json. Licence fontu je v assets/fonts/OFL.txt. Fotografie jsou ilustrativní, nikoli ukázky vlastních realizací.
